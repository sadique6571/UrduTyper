# UrduTyper 2.0

Modern Urdu typography editor for Android.

This repository is being migrated from [UrduTyper_Clean](https://github.com/iNomNom/UrduTyper_Clean), incorporating features from [UrduTyper](https://github.com/iNomNom/UrduTyper).

Planned stack: Kotlin, Android XML/Material, Firebase Authentication, Cloudflare Workers and R2 for project backups.

> Work in progress. Build and runtime verification pending.
