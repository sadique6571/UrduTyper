# Studio polish 1.3.1

- All inspectors start with the artwork collapsed, leaving room for controls. Show/Hide canvas is independent from Compact/Expand sheet height. The preference is remembered; selecting a word temporarily reveals artwork.
- Word sync Review includes a global-time waveform, pinch/button zoom (1–12×), horizontal panning, tappable word blocks and draggable start/end/move handles. Numeric fields remain available for missing timestamps and precise correction. Boundaries respect voice offset, selected trim, ordering and the 60-second cap. Waveform decoding runs off the main thread.
- Selecting a word highlights it on the inspector canvas. Loop word opens the shared preview around that word, repeatedly playing its voice interval; loop can be switched off. Listen still plays forward normally.
- A cancelled/interrupted model download retains private partial bytes. Resume sends Range and If-Range when a validator is available, restarts if the server ignores Range, checks Content-Range and validates the full pinned SHA-1 before atomic installation. A corrupted payload cannot replace an existing model. Discard partial download removes saved bytes. Model import still cleans cancelled temporary files.
- Analysis shows stage, percentage and elapsed time; download shows bytes and elapsed time. Native analysis percent describes the engine stage and is not a guaranteed time estimate. Stop remains available, work stays off the UI thread.
- Full-screen preview has Auto/Smooth/High settings, saved locally and independent from export. Smooth renders at 360px; High at 720px; Auto begins at 360/540 depending on app memory class and lowers to 360 after sustained slow frames. No export resolution, project typography or timing is changed.
- Animated canvas/inspector rendering uses one background worker and at most one pending snapshot, dropping queued stale scrub positions. File images decode off the editor UI thread. Background resource drawables and image/text layouts are cached. Local StudioPerformance logs record frame count/mean milliseconds and decode/cache counters; no artwork text/audio is logged. Diagnostics uploaded by CI include these observations; real-device RAM/heat measurements remain device QA.
- Video export uses a theme-matched gold determinate fill from 1 to 100%, stage text, elapsed time and cancellation. Rendering/audio progress occupies 1–95%, publication 97%, and 100% is reserved for the completed saved file. Percentages measure work stages, not elapsed-time estimates. Screen remains awake during export.
- Exports first save the draft and an atomic snapshot journal. Incomplete outputs use .pending and do not appear in Saved animations. Encoding and audio temporary files are removed after failure/cancellation. Free space is checked. Failed export offers exact-snapshot Retry or Change quality. After process interruption, reopening the editor offers Retry export / Later / Discard export; retry starts encoding from the beginning. Explicit Cancel clears the retry request. Finished local videos are preserved even if gallery publication is unavailable, and can be shared from Saved animations.

No online video generation or lip-sync was added. Offline speech still needs one model download/import and real Urdu recording review.
